## 🔧 How to Use

### Local Development

```bash

git clone https://github.com/SivakrishnaBoya/Portfolio.git

# Navigate to project
cd Portfolio

# Open in browser
open index.html
```

### Deploy on Render

1. Connect your GitHub repository to Render
2. Create a new Static Site
3. Build Command: `npm run build` (if applicable)
4. Publish Directory: `.` (root)
5. Deploy!
